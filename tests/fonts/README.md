These tiny original fonts are MIT-licensed fixtures generated by
`tools/generate_test_fonts.py` using FontTools 4.60.1. They contain simple
rectangles and frames:

- `mono.ttf`: A/M/space for baseline rendering tests.
- `color.ttf`: a two-color COLRv0 glyph at U+1F600 and U+F0001, deliberately
  competing with monochrome supplementary private-use icons.
- `proportional.ttf`: narrow/wide letters, a negative bearing, a combining mark
  with GPOS attachment, Hebrew, and a wide frame shared by an `ii` ligature and
  icons at U+E0B0, U+F0001, and U+100001.
- `icons.ttf`: the same private-use frames without `M` or ordinary text, testing
  fallback selection and symbol-only cell metrics.

They are not intended for user-facing text. The frame's four thick edges and
empty center distinguish complete fitting from clipping in pixel assertions.

Normal builds/tests use the committed fonts and need no Python packages.

`styled-regular.ttf`, `styled-bold.ttf`, `styled-italic.ttf`, and
`styled-bolditalic.ttf` form a real four-face family (`Vertex Test Styled`).
Distinct outlines and style flags test style selection before shaping. U+E700
in the icon fixtures tests ordinary private-use glyphs independently of the
procedurally rendered Powerline separators.
